# 📝 Notes App

A full-stack Notes application built with Node.js, Express.js, MongoDB, Mongoose, EJS, and Bootstrap.

This project was built to practice backend development, CRUD operations, database integration, validation, error handling, and server-side rendering.

## 🚀 Features

- Create new notes
- View all notes
- Edit existing notes
- Delete notes
- MongoDB database integration
- Mongoose schema and models
- Form validation
- Custom error handling
- Async error handling
- Responsive UI with Bootstrap
- EJS templating with EJS-Mate
